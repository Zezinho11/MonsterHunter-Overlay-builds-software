# Fifth-generation decoration category icons

The four decoration-slot SVGs in this directory are copied without artwork
changes from `Color_00_Rank_1.svg` through `Color_00_Rank_4.svg` in
[OthelloRhin/MHW_Icons_SVG](https://github.com/OthelloRhin/MHW_Icons_SVG),
licensed under MIT. The source collection describes them as Monster Hunter:
World SVG icons. They are used only as generic decoration-slot category
symbols in World, Rise and Wilds; they do not reproduce a named jewel or claim
to be edition-specific item art.

The collection's 14 weapon-class SVGs are also used as generic weapon-class
symbols for Rise and Wilds when no individual equipment image exists. Armor
and talisman category SVGs for Rise/Wilds are the fifth-generation symbols
credited in `../rise/NOTICE.md`.

All game-derived names and marks remain associated with Capcom Co., Ltd.; this
project is unofficial and not endorsed by Capcom.
