# Rise armor-slot and talisman icon attribution

The SVGs in this directory are category icons, not renderings of a named
armor piece or talisman. They are sourced from the `src/ui_iced/icons/`
copies in [itytophile/rab](https://github.com/itytophile/rab), whose README
credits the [Monster Hunter Wiki SVG icon page by YukiHerz](https://monsterhunter.fandom.com/wiki/User:YukiHerz/SVG_Icons).
The upstream SVG metadata identifies these files as `5thGen Item Icon-*`.

The Monster Hunter Wiki states community content is available under
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) unless noted.
Attribution is to YukiHerz and the Monster Hunter Wiki page above; the RAB
repository is recorded as the rediscovery/mirror path. No changes to the SVG
artwork were made. Underlying Monster Hunter game marks/art remain associated
with Capcom Co., Ltd.; this project is unofficial and not endorsed by Capcom.

Files included: `armor-arms.svg`, `armor-chest.svg`, `armor-head.svg`,
`armor-legs.svg`, `armor-waist.svg`, and `talisman.svg`.
