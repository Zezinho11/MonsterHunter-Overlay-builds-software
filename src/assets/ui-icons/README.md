# Monster Hunter UI icons

These element/status PNGs are sourced from the `mh-monster-info` project:

- https://github.com/TanukiSharp/mh-monster-info
- Source path: `doc/images/`
- License: MIT for the repository assets; the visual marks remain property of their respective owners.

The set is used for fire, water, thunder, ice, dragon, poison, paralysis, sleep, blast, stun and exhaust/fatigue. Damage-type headers (`cut`, `blunt`, `ammo`) retain the local fallback symbols because the audited source does not provide equivalent game UI assets for those three hitzone columns.
